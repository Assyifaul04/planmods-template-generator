# Fabric

A Minecraft mod built with Fabric.

## Development

### Setup

1. Clone the repository
2. Run `./gradlew build` to build the mod
3. Run `./gradlew runClient` to start Minecraft with the mod

### Requirements

- Java 21
- Gradle 8.11
